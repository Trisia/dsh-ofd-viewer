# 常见问题

## 右侧栏点 `.ofd` 没有预览，或提示无法打开

按顺序确认：

1. 插件是否已安装并在当前 profile 中启用（**设置 → 插件**）；
2. 安装后是否重启过 DSH Web 并刷新了页面；
3. DSH 版本是否满足 `dsh >= 0.2.1-rc.2`。右侧栏预览依赖宿主的文档预览扩展点
   （`sidebar.right.tab.document` 插槽与 `.ofd` 渲染器注册），宿主版本过旧时没有该扩展点。

宿主版本偏旧时，可以改用另外两个入口：输入框附件卡片上的「查看」，或 OFD 面板右上角的 `＋`。

## 面板打开了，但显示“没有待预览的 OFD 文件”

面板只展示通过附件「查看」或面板 `＋` 打开过的文件；右侧栏预览走的是另一条路径，不会写入面板。
先用附件卡片上的「查看」或 `＋` 选择文件即可。

## 文件名、正文发虚或缺字

阅读器依赖宿主半提供的字体路由：

```text
/ofd-viewer-plugin/fonts/source-han-serif-sc.woff2
/ofd-viewer-plugin/fonts/source-han-sans-sc.woff2
```

在浏览器里直接打开该地址，返回 200 说明字体路由正常；返回 404 说明宿主半没有激活。
此时查看 DSH 启动日志里是否有插件导入错误（例如缺少依赖包），修正后重启。

字体只覆盖常用汉字与常见标点，CJK 扩展区（ExtA–ExtE）等生僻字仍可能缺字，
具体范围见 [内置字体说明](../assets/fonts/NOTICE.md)。

## 深色主题下阅读器还是浅色

这是刻意设计。阅读器固定使用浅色文档底色，白色纸张与工具栏浅色文字在深色宿主下依然清晰；
跟随宿主切到深色时，出现过文字与背景对比度不足的问题。

## `ofd_read` 读不到扫描件里的字

`ofd_read` 只抽取 OFD 中的 `<TextCode>` 文本，不做 OCR。扫描件、纯图片页需要先用
MinerU 一类的 OCR 工具转成文本再交给模型。

## 草稿附件没有「查看」按钮

只有通过宿主校验、上传完成的附件才会出现「查看」。上传中显示「上传中」，失败时显示「上传失败」
和重试按钮，此时先重试上传。另外「查看」只对 `.ofd` 文件出现，其他格式的附件卡片保持宿主原样。

## 大文档很卡

数千页文档首屏会更慢，且同一个 OFD 在多个侧栏标签页各建一个阅读器实例，内存随实例数线性增长。
建议一次只开一个标签页，看完就关掉。
